# Security Policy

## Supported version

Security fixes are applied to the branch used for the published MobileMem project page.

## Reporting a vulnerability

Please use the repository's private GitHub security-advisory form. Do not open a public issue for
vulnerabilities that expose visitor data, unpublished research samples, or third-party credentials.

Useful reports include a minimal reproduction, affected browser and operating system, expected
impact, and any suggested mitigation. This is a static site, so reports should focus on published
asset exposure, unsafe third-party scripts, cross-site scripting, and deployment configuration.
