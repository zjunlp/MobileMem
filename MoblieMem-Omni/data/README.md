# `data/` — Dataset Placeholder

Local placeholder for dataset files. The released benchmark lives on
HuggingFace (`zjunlp/MobileMem-Omni`); pipeline outputs are written to
`output/` (gitignored). The evaluation tooling under `eval/` expects
`data/Raw/` (stage5/stage10 inputs) and writes converted files to
`data/Locomo/` — see `eval/README.md`.
